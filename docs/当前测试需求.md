## 保留的 L 形机关场景

1. 玩家踩住 1 号压力板，让感知点从底部进入右墙。
2. 感知点到达右墙铃铛旁，点击铃铛，使其振动并触发平台向左移动。
3. 感知点进入横移平台，随平台向左移动；上方另一个平台下落。
4. 感知点必须及时向上转移到下落的平台。
5. 同时玩家跑到 2 号压力板，接通上方平台和另一端的通道。
6. 感知点通过连桥到达出口。

当前原型设置：铃铛触发后，1 号通道保持接通；2 号压力板需要持续踩住。失败后可按 R 重置。这些时间、速度和距离均可调。

场景文件：`scenes/levels/l_relay_puzzle.tscn`。

## 当前操作

- A / D 或左右方向键：身体移动。
- 鼠标移动：自由移动感知点，墙内位置可发波，墙外位置点击无效。
- 鼠标左键：铃铛交互；声波测试场景中用于发射声波。
- R：重置测试。
- Esc：暂停并释放鼠标。

详细启动与调参说明见根目录 `README.md`。
