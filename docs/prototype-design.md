# 早期声波观察方案（历史记录）

本文保留早期探索过程。当前已关闭局部观察与视野死亡，默认测试声波推力跳跃；以 `当前测试需求.md` 和根目录 README 为准。

## 已确认的玩法

玩家与鼠标是独立操控。玩家只能在墙体外移动，鼠标控制的感知点只能在墙体内部移动；脚下平台算墙体。第一段用一块左右往返的平台把起点和对岸连起来，要求两者一起通过。感知点离开视野则玩家死亡。

画面使用最简黑白；感知点不使用眼球造型。地形、身体与生物均不显示填充本体，主要通过声波碰撞后短暂浮现的边缘感知空间。

## 本版默认实现

- 开放、可来回探索的横版场景，第一段通过后仍可操作。
- 身体有重力、跳跃、落地碰撞、跳跃缓冲和短暂离地宽容。
- 感知点使用相对鼠标移动；整个保守碰撞区域必须处于墙体的几何并集中，防止跨空隙传送。
- 可移动平台在靠岸时停留，允许感知点与身体分别进入或离开。
- 镜头跟随身体；默认隐藏身体，用脚步和轻微静止声源保留定位线索。
- 感知点周期探测、脚步和生物动静驱动回声。只显示声波已到达的外边缘片段，随后淡出。
- 玩家和生物无眼球、面孔或其他恐怖造型。感知点是小圆点与细环。
- F1 打开独立的开发调试视图，方便摆放瓦片、检查碰撞和操控。

## 结构

关卡负责组合复用场景与连接声源事件。Player 发出脚步/落地事件；Creature 发出移动声源事件；WallPlatform 管理几何尺寸和往返运动；WallEye 只负责输入与墙内约束；Sonar 负责声波到达时间和外边缘绘制；HUD 独立显示提示和状态。

## 验收

在真实 Godot 物理中，键盘与鼠标分别将身体、感知点送上平台，随平台过河，再进入对岸。检查越界、靠岸转移、掉落、视野死亡和重生。使用实际图形渲染截图，确认正常模式下墙体内部和角色本体为黑，仅声波命中的边缘出现线条。
