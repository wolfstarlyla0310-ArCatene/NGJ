# 大地图制作手册

面向直接在 Godot 编辑器里编辑 `scenes/world/big_map.tscn` 的人。

## 1. 场景结构

```
BigMap (world_map.gd)
├─ Terrain        TileMapLayer：整张地图的白盒地形（16×16 一格，自带物理层）
├─ Breakables     Lv1 / Lv2 两层可破坏玻璃（脚本生成碰撞）
├─ Noise          TileMapLayer：红色噪音区（纯视觉，无碰撞）
├─ Spikes         TileMapLayer：刺图格（透明图块，定期发红色脉冲；击杀看刺格本体）
├─ Triggers       TileMapLayer：无碰撞触发方块（踩上去发白色 3 格声场）
├─ Barriers       TileMapLayer：声场屏障（被声场覆盖时显形挡人）
├─ Doors          容器：摆放 door.tscn（32×32 门陷阱）
├─ Animals        容器：摆放 animal.tscn（受重力动物）
├─ DoorTiles      TileMapLayer：解谜门格子（door_tileset.tres，含整格碰撞）
├─ Buttons        容器：摆放 button_once.tscn / button_rebound.tscn
├─ DoorManager    PuzzleDoorManager：门格分组、按钮接线、开合/组锁/重置
├─ Objects        Checkpoint 存档点标记
├─ Player         玩家（不可见，只有声场可见）
├─ Camera         Camera2D
├─ RoomCamera     room_camera_controller.gd（已把 camera/world 接好）
├─ Rooms          Room1 / Room2 / …… 房间框
└─ SoundFields    运行时声场容器（白色玩家声场 + 红色刺/死亡声场）
```

节点名是约定：`Terrain`、`Rooms`、`Objects`、`Player`、`Camera` 不要改名。

运行时只让**玩家所在房间 + 上下左右相邻房间**内的 `Checkpoint` / `Animal` / `Button` 参与处理与渲染；其它房间的节点保留在场景里，但 `process_mode = DISABLED`、不可见。进入新房间后自动切换。`DoorTiles` / `DoorManager` 保持全局（有一扇门跨房间）；噪音可见性只扫描声场覆盖到的格子。

## 2. 画地形

1. 选中 `Terrain`，在 TileMap 面板选择 `whitebox_tileset.tres`。
2. 用 **Terrain** 笔刷（而不是单块笔刷）绘制，图集会自动按 47 格 blob 规则连接。
3. 地形格是 **16×16 像素**，白盒图集带完整物理层；`Terrain` 的 `collision_enabled = true`，画出来就能站。
4. 地形节点保持在原点、无缩放/旋转（房间矩形使用世界坐标）。
5. 玩家跳跃上升顶到天花板（tile）时会发声场：**起跳瞬间头顶没有净空（约 ≤2px）→ lv2 黄色波，持续 2 秒**；有净空 → lv1 蓝色波（与小跳落地 lv1 相同）。可用于触发解谜按钮或震碎玻璃；撞墙与落地不会误触发。
6. 玩家**贴着墙壁按 A/D** 时，会按与走路相同的节奏（每 32px 等效）发出 lv0 白色声场；松开或离墙停止。

## 3. 画玻璃与噪音

- 玻璃：选中 `Breakables/Lv1` 或 `Lv2`，用各自的 47 格 blob 图集（Terrain 笔刷）绘制。运行时每个 16×16 格会自动生成碰撞体；只有同等级声场能震碎。
- 噪音：选中 `Noise`，用 `noise_tileset.tres` 的红色单格刷出区域。噪音没有碰撞；玩家身体碰到后进入 **0.5 秒冷却**，冷却结束时仍接触且中心不在声场内才死亡。
- 只有被**单个声场完整覆盖**的噪音格才会暂时隐藏；部分重叠不隐藏，隐藏格仍然致命。
- 玩家/存档点/动物/触发生成的声场会**吸附到 16px 网格**（左上角落在格线上），因此声场覆盖到的噪音格按整格隐藏。
- `Breakables` 与 `Noise` 不会在运行时自动补内容；留空就是没有。

## 3b. 画刺图格

- 选中 `Spikes` 层，在 TileMap 面板选择 `spike_tileset.tres`，直接画/刷。图块在编辑器里显示为红色叉/方框，方便摆放；运行时整个 `Spikes` 层隐藏，所以游戏里看不到图格，只看到它发出的红色声场。
- 每个刺格每 **1 秒**触发一轮，连续发 **3 个红色脉冲短声场**（间隔 0.1 秒、单个 0.2 秒、视觉边长 3 格 = 48px）。
- 红色脉冲只是视觉；玩家身体碰到**刺格本身（16×16）**才死亡。刺按 **lv0** 处理，**不震碎玻璃**；不提供噪音免疫，也不会隐藏噪音。
- 玩家死亡时会在死亡位置额外发出一个红色、边长 5 格 = 80px 的声场（纯视觉）。
- 刺接触 **lv2（第三级、最大的落地声场）** 时会消失（运行时不再发射红色声场）；lv0/lv1 不会摧毁它。按 R / 死亡重置存档点房间时会随房间恢复。
- 刺层的 `sound_fields` / `breakables` 已在场景里接好；「校验地图」会检查这两条接线。

## 3c. 画触发方块

- 选中 `Triggers` 层，在 TileMap 面板选择 `trigger_tileset.tres`，直接画/刷。图块在编辑器和运行时都显示（当前使用 `assets/tiles/wind.png`）；它**没有碰撞箱**，玩家可以直接穿过。
- 玩家站在触发格上时，每 **0.5 秒**发出一次**白色 3 格声场**（48px）。它和玩家声场一样是安全区：可隐藏噪音、提供噪音免疫；**不震碎玻璃**。
- 冷却由触发层统一控制，站着不动会持续按 0.5 秒触发，离开触发格后停止。
- 触发层的 `player` / `sound_fields` 已在场景里接好；「校验地图」会检查这两条接线。

## 3d. 画声场屏障

- 选中 `Barriers` 层，用 `barrier_tileset.tres` 直接画/刷。图块在编辑器里可见；运行时未激活时以 20% 透明度显示、无碰撞。
- 被任意声场覆盖时立即显形并获得碰撞，挡住玩家；玩家紧贴移动也会被拦住。
- 声场消失后再保持 **1.2 秒**完整显形，然后回到 20% 透明状态。
- 存档点每 0.2 秒发出的 80px 声场也会激活屏障，因此存档点附近的屏障会长期保持显形/碰撞。
- `Barriers.sound_fields` 已在场景里接好；「校验地图」会检查这条接线。

## 3e. 门与动物

### 门

- 从 `scenes/world/door.tscn` 拖一个 `Door` 到 `Doors` 容器下。门体 32×32 深红色，持续发出 16~48px 的红色脉冲声场。
- 任何发声活物（玩家、动物）接触门体 → 被吃掉，门消失；门的红色脉冲碰到**白色声场**时，会吃掉白声场的主人（玩家 lv1 蓝色 / lv2 黄色声场不触发这条规则）。
- 门被吃掉后隐藏、脉冲消失；按 R / 死亡重置存档点房间时随房间恢复。
- 门通过 `sound_fields` 组自动找到声场容器，不需要手动接线。

### 动物

- 从 `scenes/actors/animal.tscn` 拖一个 `Animal` 到 `Animals` 容器下。动物是 16×16 的不可见物体（无贴图），受重力影响。
- 附近出现 lv1 声场时，动物向背离声源的方向水平移动；移动时每 `wave_interval_pixels`（16px）发出一个由 `move_wave_side_cells`（默认 1 格）控制的白色声场；静止时按 `idle_wave_interval`（当前 1.0 秒）间歇发出一个由 `idle_wave_side_cells`（默认 1.4 格）控制的 lv0 白色声场；持续时间/扩散速度由 `wave_lifetime` / `wave_expand_duration` 调整。
- 两个声场边长都在 Animal 检查器的 **「声场」分组**里用滑条调整（单位：16px 格）。
- 动物会被门的红色脉冲（通过它的白色声场）或门本体吃掉。

## 3f. 画按钮与谜题门

- **门**：选中 `DoorTiles` 层，使用 `resources/door_tileset.tres`（复制自 CCCAT 的 47 格门图集），用 Terrain 笔刷直接画门格。四邻相连的门格自动算作一扇门；开门 = 擦掉门格，关门 = 按开局快照回填。门格自带整格碰撞，玩家无法穿过。
- **按钮**：从 `scenes/world/button_once.tscn`（一次性）或 `button_rebound.tscn`（回弹）拖一个到 `Buttons` 容器下，对齐到 16px 格中心。
- **触发**：按钮只响应 **lv1 及以上声场**（玩家落地波）；lv0 的走路/起跳/存档点/触发/动物声场不会触发。
- **接线**：在按钮检查器的 `Door Cells` 里填目标门内**任意一格**的格坐标（填一格代表整扇门）。保存并运行一次，输出面板会打印 `[PuzzleDoorManager]` 门清单（每扇门的编号与全部格子），照它填即可。
- **开合规则**：一扇门连接的按钮必须**全部**被触发才开门；没有连接按钮的门永远关闭。一次性按钮首次触发后永久锁定；回弹按钮在声场消失后松开。
- **组锁**：同一扇门连接 **≥2 个回弹按钮**时，只要它们被同一个/一组声场同时触发，整组永久锁定（CCCAT 规则）；单按钮门只临时打开。
- **重置**：按 R / 死亡时，存档点房间内的解谜门恢复关闭，该房间按钮的锁定状态清除。
- 按钮贴图 `assets/tiles/buttom.png`：左列熄灭 / 右列点亮，上行一次性 / 下行回弹。

## 4. 放存档点

- 从 `scenes/world/checkpoint.tscn` 拖一个 `Checkpoint` 到 `Objects` 下。
- 位置就是重生位置（默认直接当玩家中心坐标用）；它在编辑器里画成白色小方框。
- 存档点**必须实际接触 Checkpoint 才更新**；只进入房间不再自动绑定。房间内没有 Checkpoint、或还没接触过任何 Checkpoint 时，重生点使用玩家当前位置（开局位置/起始锚点）。
- 每个房间建议放一个；「校验地图」会给出提示。
- 每个存档点每 **0.2 秒**发出一个 **5 格 / 80px** 的白色 lv0 安全声场（`emitter` 为空，门不会吃它）；存档点周围因此是永久噪音安全区。
- 检查器「声场」分组可调：`fields_enabled`（临时关闭）、`field_side_cells`（默认 5 格）、`field_interval`（默认 0.2 秒）、`field_lifetime`（默认 0.5 秒）。

## 4b. 设置起始房间

- 选中 `BigMap` 根节点，在检查器的 **Start Room** 里指定一个 `Room` 节点（留空则使用玩家在场景里的初始房间）。
- 开局时玩家会被放到该房间的 Checkpoint；房间没有 Checkpoint 则放到房间中心。若玩家被直接放在 Checkpoint 上，第一物理帧的接触会绑定它；否则需要自行走到 Checkpoint 才更新存档点。
- 「校验地图」会检查 Start Room 是否指向 `Rooms` 下的有效房间，并在该房间没有 Checkpoint 时给出提示。

## 5. 添加/调整房间框

- 打开 `big_map.tscn` 后，工具栏出现 **添加房间** / **校验地图**（插件 `addons/room_editor`）。
- **添加房间**：在 `Rooms` 下新建一个 1152×648 的 `Room`，摆在已有房间右侧 32px 处。
- 选中 `Room` 节点：
  - 拖 8 个手柄缩放；拖边框整体平移；
  - Shift + 点房间内部可加选/减选；
  - 拖动时按住 Shift 锁定单轴；
  - Ctrl+Z 撤销。
- `Room.rect` 同时决定相机取景范围与 R 重置范围。房间互相重叠时，归属按 `Rooms` 下的节点顺序决定。

房间尺寸建议：

- 1152×648（当前模板）：相机 zoom ≈ 1.02，正好一屏。
- 更小的房间会让相机放得更大；超过 1152×648 时相机会缩小，但受 `min_zoom = 1.0` 限制，太大的房间可能无法完整入屏。

## 6. 校验地图

点 **校验地图**，会检查：

- `Terrain` 存在、有 TileSet、有格子、`collision_enabled`、图集带物理层、变换为单位变换；
- `Player`、`Camera`、`RoomCamera` 存在，且 RoomCamera 的 `camera` / `world` 已接线；
- `Rooms` 至少一间、尺寸非零、无重叠（重叠给提示）；
- 所有 `Terrain` 格、`Breakables/Lv1`、`Lv2`、`Noise` 格都落在某个房间内；
- `DoorTiles` 存在 TileSet、物理层、`collision_enabled`，且门格落在某个房间内；
- `DoorManager.doors_layer` 指向 `DoorTiles`、`buttons_root` 指向 `Buttons`；
- 所有 Checkpoint 在 `Objects` 下且落在某个房间内；玩家落在某个房间内；
- 每间房是否有 Checkpoint（没有只会提示；未接触 Checkpoint 前重生点使用玩家当前位置）。

问题会写到「输出」面板，同时弹窗汇总。

## 7. R 与存档点规则

- R / 噪音死亡：清空声场 → 只还原**存档点所在房间**的玻璃 → 玩家回到存档点 → 相机瞬时 snap 到该房间。
- 解谜门：存档点房间内开着的门恢复关闭，该房间的按钮锁定状态清除；其它房间的门保持现状。
- lv2 大跳/零净空顶头声场持续 **2 秒**后自动消失；lv0/lv1 声场会在 0.5 秒后自动消失。
- 存档点只记录一个世界坐标，不写磁盘；重启游戏不会读档。没接触过任何 Checkpoint 时，R/死亡回到出生点（起始房间锚点或玩家初始位置）。
- 其它房间被震碎的玻璃不会被 R 还原，属于正常行为。

## 8. 常见问题

- **画了墙却没有碰撞**：检查 `Terrain.collision_enabled` 是否为 true，以及 `whitebox_tileset.tres` 是否有物理层。
- **房间框盖不住地形**：房间矩形是世界坐标，地形节点必须在原点且无缩放。
- **相机不切房间**：确认 `RoomCamera` 的 `camera` 指向 `Camera`、`world` 指向根节点；玩家要真正走进新房间（有 4px 滞回）。
- **R 回到了别的房间**：存档点绑定的是「进房时那个房间的 Checkpoint 或进入位置」；检查该房间的 Checkpoint 摆位。
